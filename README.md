# مشكاة — Mishkat

تطبيق تعليمي تفاعلي مخصص للنساء لتعلّم الفقه.

## ما تم تطبيقه
- هوية التطبيق: مشكاة + شعار مشكاة.
- رفيقتي كشخصية تفاعلية بطابع شخصيات الألعاب التعليمية، مع 10 أزياء مختلفة في الشكل والتطريز واللون.
- درس يومي واحد فقط.
- مدة الجلسة المستهدفة: 20 دقيقة، موزعة إلى 10 دقائق للدرس، 5 دقائق للأساسيات، و5 دقائق للمسائل الفقهية.
- دعم 20 شكلًا تفاعليًا للأسئلة.
- التغذية الراجعة وتسجيل الأخطاء وكبسولة زمن.
- قفل الدرس التالي حتى اليوم التالي بعد إكمال جلسة اليوم.
- بوابة دخول توضح أن التطبيق مخصص للنساء.

## التشغيل
```bash
npm install
npx expo start
```
