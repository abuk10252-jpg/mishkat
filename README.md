# زادي — نسخة تجريبية (بناء أولي)

تطبيق تعليم فقهي (وبعدها قرآني) للنساء، بأسلوب دولينجو، شغال أوفلاين بالكامل.
دي **نسخة تجريبية عشان تشوف الفكرة شغالة عمليًا** — مش النسخة النهائية، ومفيش فيها
غير درس واحد تجريبي (فروض الوضوء) عشان تختبر كل أشكال الأسئلة.

## تشغيل المشروع

```
npm install
npx expo start
```

افتح Expo Go على موبايلك وامسح الـ QR code، أو اضغط `a` لتشغيله على محاكي أندرويد.

## هيكل المشروع

```
app/
  _layout.tsx        شاشة البداية + إعداد RTL
  index.tsx           الشاشة الرئيسية (حديقة العلم + رفيقتي)
  lesson/[id].tsx      محرك الدرس المتصل (تعليم + سؤال متداخلين)
src/
  theme/colors.ts      نظام الألوان الحي (يتغير مع وقت اليوم + التقدم)
  utils/timeOfDay.ts   حساب فترة اليوم التقريبية (بدون نت)
  utils/storage.ts     تخزين التقدم محليًا (XP, قلوب, ستريك, الأخطاء)
  components/Rafiqati.tsx   مكون رفيقتي (شكل مجرد مؤقت لحد ما تجهز الرسمة)
  data/lessons/        محتوى الدروس (ملفات JSON)
```

## اللي شغال فعليًا في النسخة دي

- تدفق درس متصل: تعليم ← سؤال ← تعليم ← سؤال (مش شاشتين منفصلتين)
- 5 أشكال أسئلة: اختيار من متعدد، كتابة حرة، عكس الأدوار (صحح رفيقتك)، ترتيب، ولحظة نية قبل الدرس
- تخزين محلي للتقدم (XP، قلوب، إتقان كل وحدة) — يفضل موجود حتى من غير نت
- تسجيل الأخطاء تلقائيًا (الأساس اللي هنبني عليه "كبسولة الزمن" لاحقًا)
- الألوان بتتغير حسب وقت اليوم فعليًا (جرب تفتحه فجر مقابل ضحى)
- اهتزاز مختلف عند الإجابة الصح والغلط (Haptics)

## اللي لسه ناقص (الخطوة الجاية)

- محتوى حقيقي بدل الدرس التجريبي — بمجرد ما تديني المصادر، نحولها لملفات JSON زي الموجودة
- الرسمة الفعلية لرفيقتي (دلوقتي شكل مجرد بس، مكتوب في الكود فين تستبدلها)
- "كبسولة الزمن" الفعلية (السجل موجود، الشاشة اللي بتعرضها لسه ما اتبنت)
- حديقة بصرية حقيقية (دلوقتي دوائر بسيطة، محتاجة رسمة فعلية للنباتات)
- خزينة الحكمة (الدالة جاهزة في storage.ts، محتاجة شاشة تعرضها)
- مسار القرآن (بعد ما الفقه ياخد شكله الكامل)
- الأيقونة الحالية (assets/icon.png) شكل مبدئي بسيط — تقدر تستبدلها بتصميم احترافي لاحقًا
